# NOVACORE Technologies

**Building the next generation of technology.**

NOVACORE Technologies is a technology initiative focused on custom software, automation, digital products, design, and dependable infrastructure.

## Website

The official landing page is built with Next.js, React, and TypeScript. It uses a responsive dark corporate identity with a restrained blue accent palette.

## Capabilities

- Software development — websites, web apps, APIs, dashboards, and custom systems.
- Automation — bots, integrations, and workflow systems.
- Digital products — SaaS, platforms, and product engineering.
- Design & experience — UI/UX, prototyping, and design systems.
- Infrastructure — cloud deployment, CI/CD, and reliability.
- Research & development — prototypes and engineering experiments.

## Run locally

Requirements: Node.js 20 or newer.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Quality checks

```bash
npm run typecheck
npm run build
```

GitHub Actions runs both checks on pushes and pull requests targeting `main`.
